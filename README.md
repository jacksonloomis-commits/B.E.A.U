# B.E.A.U

**Behavioral & Executive Assistance Utility** — a browser-based personal assistant experience.

## Frontend preview

The current version is a static, frontend-only prototype. Open `index.html` in a browser or enable GitHub Pages to host it.

### Included
- Polished sign-in and create-account screens (demo only)
- Responsive personal dashboard and sidebar navigation
- Animated assistant orb and welcome panel
- Quick-action cards with preview feedback
- Live date/time greeting
- Desktop, tablet, and mobile layouts

### Important
Authentication is simulated. No credentials are stored or transmitted, and assistant actions are visual placeholders. Do not enter a real password.

### Technology
HTML, CSS, and vanilla JavaScript in a single static page. Google Fonts are loaded externally when online.
